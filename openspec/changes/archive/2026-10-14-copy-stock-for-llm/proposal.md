# Proposal

## Why

ผู้ใช้อยากขอความเห็นที่สองจาก LLM ตัวอื่นก่อนตัดสินใจซื้อ แต่หน้ารายละเอียดหุ้น (`/stocks/<symbol>`) แสดงข้อมูลกระจายหลายส่วน ทั้งตาราง tooltip และป้าย ถ้าคัดลอกจากหน้าเว็บตรงๆ จะได้ข้อความที่ไม่มีโครงสร้าง ตกหล่นคำอธิบายวิธีคิด fair value และ LLM อ่านผิดได้ง่าย

## What Changes

- เพิ่มปุ่ม "คัดลอกให้ LLM" บนหน้ารายละเอียดหุ้น กดแล้วคัดลอกข้อมูลทั้งหน้าเป็น Markdown ลง clipboard และแสดงว่าคัดลอกแล้ว
- เนื้อหาที่คัดลอก:
  - **Prompt นำ (ภาษาอังกฤษ):** บอก LLM ว่าเป็นความเห็นที่สองของหุ้นใน SET สำหรับนักลงทุนแนว value ที่ถือราว 1 ไตรมาส ข้อมูลมาจากแหล่งไม่เป็นทางการ (yfinance, thaifin) ให้ตรวจความสอดคล้องของตัวเลข แย้งข้อสรุปได้ และตอบเป็นภาษาไทย
  - **ข้อมูลทุกส่วนที่หน้าแสดง:** ชื่อหุ้น, sector, market, ราคาปิดและวันที่, สถานะ candidate และเหตุผลที่ไม่ผ่าน, gates, fair value panel (summary, ป้ายเตือน, ทุกเกณฑ์รวมที่เป็น N/A พร้อมเหตุผล), CDC, risk/reward, catalyst hints และ event calendar
  - **คำอธิบายวิธีคิด:** แต่ละเกณฑ์ของ fair value และ MoS ประโยคละหนึ่งบรรทัด เพื่อให้ LLM ตัดสินได้ว่าเกณฑ์ไหนเหมาะกับหุ้นตัวนี้
  - **ป้ายกำกับเป็นภาษาอังกฤษ** ส่วนเหตุผลที่ engine เขียน (เช่น เหตุผลที่ไม่ผ่าน gate) คงเป็นภาษาไทยตามที่ได้จาก engine
- หุ้นที่ยังไม่มีผลประเมินหรือ fail ใน batch ล่าสุดยังคัดลอกได้ โดยระบุสถานะนั้นแทนส่วนที่ไม่มีข้อมูล

นอกขอบเขต:
- ข้อมูลรายไตรมาสย้อนหลัง (EPS, ส่วนผู้ถือหุ้น, market cap, yield) ที่ใช้คำนวณ band ต้องเพิ่ม field ใน engine ทำเป็น change แยกถ้าจำเป็น
- ส่งข้อมูลไปที่ LLM โดยตรงหรือเรียก API ของ LLM ผู้ใช้วางเองในแชท
- ปุ่มคัดลอกในหน้า candidate list หรือการคัดลอกหลายหุ้นพร้อมกัน
- ดาวน์โหลดเป็นไฟล์หรือ JSON

## Capabilities

### New Capabilities
- `stock-summary-export`: คัดลอกข้อมูลของหุ้นหนึ่งตัวจากหน้ารายละเอียดเป็นข้อความที่ LLM อ่านได้ พร้อม prompt นำ

### Modified Capabilities
- (ไม่มี)

## Impact

- **Code:** เฉพาะ `web/` ได้แก่ ปุ่มแบบ client component ใน `web/app/stocks/[symbol]/` และฟังก์ชันสร้าง Markdown จาก `StockDetail` ที่หน้าได้จาก engine อยู่แล้ว ไม่แก้ engine และไม่เพิ่ม dependency
- **ความสัมพันธ์กับ change อื่น:** ไม่บล็อกและไม่ถูกบล็อกโดย `investor-type-flow` (แตะคนละหน้า) ถ้า change ในอนาคตเพิ่มส่วนใหม่บนหน้ารายละเอียดหุ้น ต้องเพิ่มส่วนนั้นในข้อความที่คัดลอกด้วย
