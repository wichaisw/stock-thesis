# Spec Delta

## ADDED Requirements

### Requirement: ป้ายงบใกล้ออก
ระบบ SHALL ติดป้ายงบใกล้ออกเมื่อกำหนดส่งงบที่ประมาณ (กฎเดียวกับ event calendar) ของไตรมาสถัดจากไตรมาสล่าสุดที่รายงานแล้ว อยู่ระหว่างวันที่ราคาของ run ถึง `flags.earnings_due_days` (default 14) วันหลังจากนั้น เหตุผลของป้าย SHALL บอกไตรมาส วันที่ และว่าเป็นค่าประมาณ ป้ายนี้ SHALL ไม่ใช้คัดหุ้นออกและไม่ใช้เรียงลำดับ

#### Scenario: งบไตรมาสถัดไปใกล้ครบกำหนด
- **WHEN** ไตรมาสล่าสุดที่รายงานแล้วคือ 2026Q2 และวันที่ราคาของ run คือ 5 พ.ย. 2026
- **THEN** หุ้นติดป้ายงบใกล้ออก พร้อมเหตุผลว่างบ 2026Q3 ครบกำหนดประมาณ 14 พ.ย. 2026

#### Scenario: บริษัทส่งงบก่อนกำหนดแล้ว
- **WHEN** ไตรมาสล่าสุดที่รายงานแล้วคือ 2026Q3 และวันที่ราคาของ run คือ 5 พ.ย. 2026
- **THEN** หุ้นไม่ติดป้ายงบใกล้ออก

#### Scenario: กำหนดส่งยังอีกนาน
- **WHEN** ไตรมาสล่าสุดที่รายงานแล้วคือ 2026Q2 และวันที่ราคาของ run คือ 15 ต.ค. 2026
- **THEN** หุ้นไม่ติดป้ายงบใกล้ออก

#### Scenario: กำหนดส่งผ่านไปแล้ว
- **WHEN** ไตรมาสล่าสุดที่รายงานแล้วคือ 2026Q2 และวันที่ราคาของ run คือ 20 พ.ย. 2026
- **THEN** หุ้นไม่ติดป้ายงบใกล้ออก
