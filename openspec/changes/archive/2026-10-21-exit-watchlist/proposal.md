# Proposal

## Why

แอปตอนนี้ช่วยแค่ฝั่งเข้าซื้อ (candidate list) แต่หลังซื้อแล้วไม่มีอะไรบอกว่าควรเตรียมขาย ควร cut loss หรือควรถือรอต่อ ทั้งที่ thesis ของเราคือเงินไม่ควรแช่ในหุ้นเกินราวหนึ่งไตรมาส ข้อมูลที่ต้องใช้ตัดสิน (CDC, fair value gate, quality, stop) batch คำนวณไว้ทุกตัวอยู่แล้ว ขาดแค่รายการหุ้นที่ถืออยู่และกฎฝั่งขาย นี่คือ follow-up `thesis-tracking` ที่วางไว้ว่าจะทำหลังใช้งานจริง

## What Changes

- ตารางใหม่เก็บหุ้นที่ถือ ผู้ใช้เพิ่มและลบเองในหน้าใหม่ แต่ละแถวมี symbol, ราคาต้นทุนเฉลี่ย และวันที่ซื้อ
- หน้าใหม่ "หุ้นที่ถือ" (ลิงก์จากหน้า candidates แบบเดียวกับ "ประวัติ candidate") แสดงหุ้นที่ถือแต่ละตัวพร้อมคำตัดสินเดียว เรียงตามลำดับความสำคัญ CUT > เตรียมขาย > รอ > ถือต่อ และป้ายเหตุผลที่ทำให้ได้คำตัดสินนั้น
  - **CUT** เมื่อเกิดข้อใดข้อหนึ่ง: ราคาปิดต่ำกว่า stop ที่ล็อกไว้ ณ วันที่ซื้อ, CDC ตัดลงเป็น bear หลังจากเคยเป็น bull อย่างน้อยหนึ่งครั้งนับจากวันที่ซื้อ, ไม่ผ่าน quality gate
  - **เตรียมขาย** เมื่อเกิดข้อใดข้อหนึ่ง: MoS gate ต่ำกว่า `candidates.min_gate_mos` (เกณฑ์เดียวกับฝั่งเข้า), CDC เป็น bull แต่ ETA ที่จะตัดลงเป็น bear ≤ `cdc.approaching_eta_days`
  - **รอ** เมื่อราคาต่ำกว่าต้นทุนแต่ไม่เข้าข้อใดข้างบน
  - **ถือต่อ** กรณีอื่น
  - ป้ายข้อมูลที่ไม่เปลี่ยนคำตัดสิน: กำไร/ขาดทุน % จากต้นทุน, ถือเกิน 63 วันทำการ, รอ CDC cross ครั้งแรก (ซื้อตอน bear)
- หน้าแสดงชัดว่ากฎฝั่งขายยังไม่ผ่าน backtest
- batch ดึงงบและ market cap ให้หุ้นที่ถือทุกตัว แม้ไม่ผ่าน liquidity filter เพื่อให้หุ้นที่ถือทุกตัวมี fair value และ quality หุ้นเหล่านี้ยังไม่ผ่าน liquidity filter และไม่เข้า candidate list

นอกขอบเขต:
- backtest กฎฝั่งขาย (change แยกภายหลัง)
- นำเข้ารายการหุ้นจาก broker, จำนวนหุ้นหรือมูลค่าพอร์ต
- แจ้งเตือน (notification) คำตัดสินอัปเดตเฉพาะตอน batch รันหรือเปิดหน้า
- เปลี่ยน candidate list หรือวิธีประเมินหุ้น
- ประวัติคำตัดสินย้อนหลังและบันทึกการขาย

## Capabilities

### New Capabilities
- `holding-exit`: รายการหุ้นที่ถือที่ผู้ใช้ใส่เอง และคำตัดสินฝั่งขาย (CUT / เตรียมขาย / รอ / ถือต่อ) พร้อมเหตุผล

### Modified Capabilities
- `quality-gate`: liquidity filter ยังตัดหุ้นที่ถือออกจาก candidate list แต่ batch ดึงงบให้หุ้นที่ถือแม้ไม่ผ่าน filter

## Impact

- **Code:** `engine/shortlist/db.py` (ตาราง `holdings` และ query), `engine/shortlist/batch.py` (`collect` ดึงงบให้หุ้นที่ถือนอก liquidity), โมดูลใหม่ `engine/shortlist/core/exit.py` (กฎคำตัดสิน, pure), `engine/shortlist/core/cdc.py` (ETA ฝั่ง bull), `engine/shortlist/api.py` (endpoint เพิ่ม/ลบ/ดูหุ้นที่ถือ), หน้าใหม่ `web/app/holdings/`, `web/lib/engine.ts`, ลิงก์ใน `web/app/page.tsx` และ test
- **ผลต่อผู้ใช้:** มีหน้าใหม่ candidate list และผลประเมินหุ้นอื่นไม่เปลี่ยน batch ดึงงบเพิ่มเท่าจำนวนหุ้นที่ถือที่ไม่ผ่าน liquidity (ไม่กี่ตัว)
- **ความสัมพันธ์กับ change อื่น:** ไม่มี change อื่นค้างอยู่ ไม่บล็อกและไม่ถูกบล็อก
