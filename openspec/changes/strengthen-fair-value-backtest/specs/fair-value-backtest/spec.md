# Spec Delta

## ADDED Requirements

### Requirement: ความไม่แน่นอนของ excess return
ตารางผลรวม SHALL แสดง t-stat และช่วงความเชื่อมั่น 95% ของ excess เฉลี่ย ของทุกกลุ่ม (แต่ละ method, median, candidate และ candidate (relative)) คิดจาก excess ต่อวันที่ทดสอบ ไม่ใช่ต่อการประเมิน ช่วงความเชื่อมั่นและ t-stat SHALL ได้ค่าเดิมทุกครั้งที่รันด้วยข้อมูลเดิม

#### Scenario: กลุ่มที่มี excess หลายวันที่
- **WHEN** กลุ่มมี excess ต่อวันที่อย่างน้อย 2 วันที่
- **THEN** แถวของกลุ่มนั้นแสดง t-stat (excess เฉลี่ย ÷ standard error ของ excess ต่อวันที่) และช่วงความเชื่อมั่น 95% ของ excess เฉลี่ย

#### Scenario: กลุ่มที่มี excess วันที่เดียวหรือไม่มี
- **WHEN** กลุ่มมี excess ต่อวันที่น้อยกว่า 2 วันที่
- **THEN** t-stat และช่วงความเชื่อมั่นแสดงเป็น "–"

#### Scenario: รันซ้ำด้วยข้อมูลเดิม
- **WHEN** รัน backtest สองครั้งด้วย cache และ `engine/config.yaml` เดียวกัน
- **THEN** t-stat และช่วงความเชื่อมั่นทุกแถวเท่ากันทั้งสองรอบ

### Requirement: ผลรวมแบบไม่นับค่าผิดปกติ
ไฟล์ผล SHALL มีตารางผลรวมชุดที่สองที่ตัดการประเมินผิดปกติ (MoS < −100% หรือ fair value > 5× ราคา) ออกจากกลุ่มของ method นั้นก่อนคิดตัววัด โดย baseline ของแต่ละวันยังเป็นค่าเฉลี่ยของหุ้นทุกตัวที่ประเมินได้ ตารางผลรวมเดิมยังนับค่าผิดปกติทุกตัว

#### Scenario: fair value เกิน 5 เท่าของราคา
- **WHEN** method ให้ fair value มากกว่า 5 เท่าของราคากับหุ้นตัวหนึ่ง ณ วันที่ทดสอบ
- **THEN** การประเมินนั้นนับในตารางผลรวมเดิม แต่ไม่นับในตารางแบบไม่นับค่าผิดปกติของ method นั้น และหุ้นตัวนั้นยังนับใน baseline ของวันนั้น

#### Scenario: median ผิดปกติ
- **WHEN** median fair value ของหุ้นตัวหนึ่งผิดปกติ
- **THEN** การประเมินนั้นไม่นับในกลุ่ม median, candidate และ candidate (relative) ของตารางแบบไม่นับค่าผิดปกติ

### Requirement: วัดผลประกอบที่ 126 และ 252 วันทำการ
backtest SHALL วัด excess return ของทุกกลุ่มที่ 126 และ 252 วันทำการหลังวันที่ทดสอบด้วยวิธีเดียวกับ 63 วัน (ผลตอบแทนรวมปันผลของกลุ่ม − baseline ของวันเดียวกันที่ระยะเดียวกัน) และ median excess แยกตาม bucket ของ MoS 63 วันทำการ SHALL ยังเป็นตัววัดหลัก hit rate วัดที่ 63 วันเท่านั้น

#### Scenario: วันที่ทดสอบที่ยังไม่ครบระยะ
- **WHEN** วันที่ทดสอบ 2026-03-31 ยังไม่ครบ 252 วันทำการ ณ วันที่รัน
- **THEN** วันที่นั้นไม่ถูกนับที่ระยะ 252 วัน แต่ยังนับที่ระยะที่ครบแล้ว และตารางแสดงจำนวนวันที่ที่นับต่อระยะ

#### Scenario: ตารางต่อระยะ
- **WHEN** รายงานผล
- **THEN** ไฟล์ผลมีตารางที่แสดง excess เฉลี่ย, ช่วงความเชื่อมั่น 95%, t-stat และจำนวนวันที่ ของทุกกลุ่มที่ 63, 126 และ 252 วัน และตาราง bucket ของ MoS มี median excess ที่ 126 และ 252 วัน

#### Scenario: ระยะยาวซ้อนกัน
- **WHEN** ระยะวัดผลยาวกว่า 1 ไตรมาส
- **THEN** ข้อจำกัดในไฟล์ผลระบุว่าช่วงวัดผลของวันที่ทดสอบที่ติดกันซ้อนกัน t-stat และช่วงความเชื่อมั่นที่ 126 และ 252 วันจึงดูแน่นอนกว่าจริง

### Requirement: candidate แบบ relative
backtest SHALL วัดกลุ่ม candidate (relative) คือหุ้นที่ผ่าน quality gate และ median MoS อยู่ใน 20% บนของหุ้นที่มี median MoS ณ วันที่ทดสอบเดียวกัน ไม่มีเกณฑ์ MoS ขั้นต่ำ ด้วยตัววัด excess และแถวสลับ MoS เดียวกับกลุ่ม candidate เดิม กลุ่มนี้มีใน backtest เท่านั้น ไม่มีผลกับ batch หรือ candidate list

#### Scenario: เลือก 20% บน
- **WHEN** วันที่ทดสอบมีหุ้น 100 ตัวที่มี median MoS
- **THEN** หุ้นที่ median MoS อยู่ในอันดับ 1–20 และผ่าน quality gate อยู่ในกลุ่ม candidate (relative) ของวันนั้น ไม่ว่า median MoS จะเป็นบวกหรือลบ

#### Scenario: สัดส่วน candidate ต่อวันที่
- **WHEN** รายงานผลต่อวันที่ทดสอบ
- **THEN** ตารางต่อวันที่แสดงจำนวนและสัดส่วนต่อหุ้นที่ประเมินได้ของทั้ง candidate และ candidate (relative)

#### Scenario: batch ไม่เปลี่ยน
- **WHEN** รัน batch หลัง change นี้
- **THEN** candidate list ยังใช้ candidate rule เดิม (ผ่าน quality gate และ median MoS ≥ `candidates.min_median_mos`)
