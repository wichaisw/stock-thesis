# Proposal

## Why

run 23 และ 24 (รันเมื่อ 15 ต.ค. 2569 เวลา 00:20) ได้ราคาจาก yfinance ที่แท่งล่าสุดเป็นวันที่ 12 ต.ค. ถึง 897 จาก 922 ตัว แต่ run บอกว่าราคาปิดวันที่ 14 ต.ค. เพราะ `price_date` ของ run คือวันที่ล่าสุดของหุ้นตัวใดก็ได้ ราคาที่ใช้จึงผิดโดยไม่มีอะไรเตือน (NSL entry 22.20 เทียบราคาปิดบน TradingView 22.8, SRICHA 17.50 เทียบ 17.8, EA 2.68 เทียบ 2.70) ส่วน run 19 (รันเมื่อ 14 ต.ค. 23:52) ได้ราคาถูก ราคาที่ผิดทำให้ entry, CDC, MoS และ candidate list ผิดตามไปทั้งหมด

## What Changes

- engine ติดป้าย "ราคาไม่อัปเดต" ให้หุ้นที่แท่งราคาล่าสุดเก่ากว่าวันที่ล่าสุดของ run (วันที่ราคาล่าสุดในบรรดาหุ้นทุกตัวที่ประเมินได้)
- หน้า candidate list แสดงบรรทัดเตือนระดับ run เมื่อมีหุ้นที่ราคาไม่อัปเดต เช่น "ราคา 897/922 ตัวเป็นวันที่ 12 ต.ค." และแสดงป้ายที่หุ้นแต่ละตัว
- หน้ารายละเอียดและข้อความที่คัดลอกให้ LLM แสดงป้ายนี้ข้างวันที่ราคา
- ป้ายนี้เตือนอย่างเดียว ไม่ใช่ gate และไม่ใช้เรียงลำดับ ผู้ใช้ตัดสินเองว่าจะรัน batch ใหม่หรือไม่

นอกขอบเขต:
- การ retry หรือดึงราคาจากแหล่งอื่นเมื่อแท่งล่าสุดขาด
- การเทียบกับปฏิทินวันทำการของ SET (ไม่มีแหล่งข้อมูลวันหยุด) จึงจับไม่ได้ถ้าหุ้นทุกตัวขาดแท่งเดียวกัน
- การทำให้ batch fail หรือตัดหุ้นออกเมื่อราคาไม่อัปเดต
- run เก่าที่รันไปแล้ว (ไม่มี field นี้จนกว่าจะรัน batch ใหม่)

ความสัมพันธ์กับ change อื่น:
- `simplify-risk-reward` แก้ requirement "ข้อมูลที่แสดงใน candidate list" ตัวเดียวกัน delta ของ change นี้เขียนต่อจากเวอร์ชันของ `simplify-risk-reward` จึงต้อง archive หลัง change นั้น ส่วน code ไม่บล็อกกัน
- ไม่บล็อกและไม่ถูกบล็อกโดย `investor-type-flow` (คนละ capability)

## Capabilities

### New Capabilities
- (ไม่มี)

### Modified Capabilities
- `market-data`: เพิ่ม requirement ตรวจหุ้นที่ราคาไม่อัปเดตเทียบวันที่ล่าสุดของ run และนับจำนวนระดับ run
- `candidate-list`: แสดงบรรทัดเตือนระดับ run และป้ายราคาไม่อัปเดตในรายการและหน้ารายละเอียด
- `stock-summary-export`: ข้อความที่คัดลอกมีป้ายราคาไม่อัปเดตข้างวันที่ราคา

## Impact

- **engine**: `shortlist/batch.py` (ติด `stale_price` หลังได้ `price_date` ของ run), `shortlist/db.py` (`latest_successful_run` คืนจำนวนและวันที่ของหุ้นที่ราคาไม่อัปเดต), tests `test_batch.py`, `test_db.py`
- **web**: `lib/engine.ts`, `app/page.tsx`, `app/stocks/[symbol]/page.tsx`, `lib/llm-export.ts` และ test
- **ข้อมูล**: ไม่เปลี่ยน schema ของฐานข้อมูล
