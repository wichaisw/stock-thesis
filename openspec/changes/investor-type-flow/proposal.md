# Proposal

## Why

ผู้ใช้อยากดูว่าแต่ละวันนักลงทุนแต่ละกลุ่ม (สถาบันในประเทศ, บัญชีบริษัทหลักทรัพย์, ต่างชาติ, รายย่อยในประเทศ) ซื้อขายในตลาด SET กี่ล้านบาท ย้อนหลังเป็นรายวัน ตอนนี้ต้องเปิดหน้า SET ดูทีละวัน และ SET แสดงเฉพาะวันล่าสุด

ตรวจแล้ว (14 ต.ค. 2026):
- API สาธารณะของ SET (`/api/set/market/SET/investor-type`) ให้แค่วันล่าสุด ส่งวันที่ไปก็ได้วันนี้เสมอ และไม่มี endpoint ย้อนหลัง ข้อมูลย้อนหลังถึงปี 1975 มีเฉพาะบริการข้อมูลแบบเสียเงินของ SET
- engine เรียก SET ตรงไม่ได้ (403 จาก Incapsula แม้ใส่ header แบบ browser) ได้เฉพาะจาก browser จริง
- yfinance และ thaifin ไม่มีข้อมูลนี้
- settrade.com (ตรวจ 15 ต.ค. 2026) ใช้ API ชุดเดียวกับ SET และโดน Incapsula บล็อกเหมือนกัน ข้อมูลครบ 4 ประเภท แต่ย้อนหลังมีแค่ค่าสุทธิสะสมรายเดือน 1 ปี (`investor-type-chart?period=1Y` ได้ 13 จุด) และ 5 วันล่าสุด (`period=5D`) ส่วนช่วง 1M, 3M, 6M, YTD ได้ 400 จึงไม่มีแหล่งฟรีที่ให้ค่ารายวันย้อนหลังครบ 4 ประเภท

ทางที่เหลือแบบไม่เสียเงินจึงเป็นการเก็บเองทุกวันหลังตลาดปิด ประวัติจะเริ่มนับจากวันแรกที่เก็บ

## What Changes

- batch ดึงมูลค่าซื้อขายตามประเภทนักลงทุนของตลาด SET ของวันนั้นผ่าน headless browser (Playwright) แล้วเก็บต่อท้ายประวัติใน DB ไม่ลบของวันก่อนๆ
- ถ้าดึงไม่ได้ batch ยังจบและบันทึกว่าดึงไม่สำเร็จ ไม่กระทบการประเมินหุ้น
- รันหลายครั้งในวันเดียวกันจะเขียนทับข้อมูลของวันนั้น (ค่าล่าสุดชนะ) ข้อมูลที่ดึงระหว่างตลาดเปิดติดป้ายว่ายังไม่ใช่ค่าปิดตลาด
- หน้าเว็บใหม่แสดงรายวัน ใหม่สุดก่อน ของทั้ง 4 กลุ่ม: ซื้อ, ขาย, สุทธิ เป็นล้านบาท
- กราฟมูลค่าสุทธิสะสมรายเดือนย้อนหลัง 1 ปีของทั้ง 4 ประเภท แบบเดียวกับหน้า settrade.com (historical-report/investor-type) มีปุ่มเปิด/ปิดแต่ละประเภท ดึงจาก `investor-type-chart?period=1Y` ในการเปิดหน้าครั้งเดียวกับข้อมูลรายวัน (ผู้ใช้เลือก 15 ต.ค. 2026)
- **BREAKING (ข้อมูล)**: เอาการเติมย้อนหลังจาก siamchart ออกทั้งหมด ได้แก่ คำสั่ง, ตาราง `investor_flow_net` พร้อมข้อมูล 242 วัน, endpoint และตารางบนหน้าเว็บ เพราะ siamchart รวมสถาบันในประเทศกับบัญชีบริษัทหลักทรัพย์เป็นกลุ่มเดียว ผู้ใช้เลือกใช้เฉพาะแหล่งที่ครบ 4 ประเภท (15 ต.ค. 2026) ประวัติรายวันจึงเริ่มจากวันแรกที่เก็บ ส่วนภาพย้อนหลัง 1 ปีมาจากกราฟรายเดือน
- งานแรกของ change นี้เป็น spike ตรวจว่า headless Chromium ผ่าน Incapsula ได้ ถ้าไม่ได้ให้หยุดแล้วกลับไปถามผู้ใช้ก่อนทำส่วนอื่น

นอกขอบเขต:
- ค่ารายวันย้อนหลังก่อนวันที่เริ่มเก็บ (ต้องใช้บริการเสียเงินของ SET) ย้อนหลังมีแค่กราฟรายเดือน
- ตลาด mai (API มีให้ เพิ่มทีหลังได้)
- ใช้เป็น gate หรือตัว sort ใน candidate list หรือสัญญาณใดๆ (ทำเป็น change แยกหลังเห็นข้อมูลจริง)
- กราฟของข้อมูลรายวันที่เก็บเอง (ทำทีหลังเมื่อมีข้อมูลพอ)
- library กราฟ (วาดด้วย SVG ในหน้าเอง ผู้ใช้เลือก 15 ต.ค. 2026)

## Capabilities

### New Capabilities
- `investor-flow`: เก็บและแสดงมูลค่าซื้อขายรายวันของตลาด SET แยกตามประเภทนักลงทุน

### Modified Capabilities
- (ไม่มี) batch เพิ่มขั้นตอนแต่ requirement ของ `market-data` เดิมไม่เปลี่ยน

## Impact

- **engine**: dependency ใหม่ `playwright` และ Chromium (~150 MB, ติดตั้งด้วย `playwright install chromium`), adapter ใหม่ใน `shortlist/sources/`, ตารางใหม่ใน `shortlist/db.py` ที่ไม่ถูกลบตอน run ใหม่, ขั้นตอนใหม่ใน `shortlist/batch.py`, endpoint ใหม่ใน `shortlist/api.py`
- **web**: หน้าใหม่พร้อมกราฟ SVG และลิงก์ไปหน้านั้นจากหน้า candidates
- **ข้อมูล**: ตาราง `investor_flow_monthly` ใหม่ และลบตาราง `investor_flow_net` (ข้อมูล siamchart) ออกจาก DB
- **เวลา batch**: เพิ่มการเปิด browser หนึ่งครั้งต่อ run (ราว 10–20 วินาที)
- **ความเสี่ยงหลัก**: SET เปลี่ยน API หรือ Incapsula บล็อก headless browser เมื่อไหร่ก็ได้ เพราะเป็นการใช้ API ที่ไม่ได้เปิดให้ใช้อย่างเป็นทางการ ใช้คนเดียวบน local เท่านั้น
- **ลำดับ**: ไม่ขึ้นกับ `cash-dividend-yield-band` (ยังเหลือ task 3.1–3.2 ซึ่งต้องรัน batch ใหม่ตอนเครือข่ายปกติ) แต่ทั้งสองแก้ `batch.py` คนละส่วน ควรทำทีละ change ส่วน change `settings-entry-point` ที่จะเอาลิงก์ "ตั้งค่า" ออกจาก header ทำให้ change นี้ไม่วางลิงก์ไว้ที่ header
