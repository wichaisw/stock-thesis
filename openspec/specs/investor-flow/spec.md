## Requirements

### Requirement: เติมข้อมูลรายวันย้อนหลังจาก InfoQuest
ระบบ SHALL มีคำสั่งที่ผู้ใช้รันเองเพื่อเติมมูลค่าซื้อและขายรายวันของตลาด SET แยกตาม 4 ประเภทนักลงทุน จากข่าวสรุปรายวันของ InfoQuest ที่เป็นของตลาด SET เท่านั้น (ไม่ใช่ SET+MAI) ทุกวันที่หน้ารายการของ InfoQuest ยังมี วันที่ของแต่ละแถว SHALL เป็นวันที่ของข้อมูลตามเนื้อข่าว ไม่ใช่วันที่ลงข่าว รันซ้ำ SHALL ไม่ทำให้มีวันซ้ำ

#### Scenario: เติมครั้งแรก
- **WHEN** ผู้ใช้รันคำสั่งเติมย้อนหลัง และ InfoQuest มีข่าว (SET) ตั้งแต่ 17 มิ.ย. 2026 ถึง 15 ต.ค. 2026
- **THEN** ประวัติมีทุกวันที่มีข่าวในช่วงนั้นครบ 4 ประเภท และต่างชาติวันที่ 14 ต.ค. 2026 คือซื้อ 53,230.15 ขาย 47,539.17 ล้านบาท

#### Scenario: รันซ้ำ
- **WHEN** ผู้ใช้รันคำสั่งเติมย้อนหลังครั้งที่สอง
- **THEN** ไม่มีวันใดซ้ำ และจำนวนวันเพิ่มเฉพาะวันที่ยังไม่มี

### Requirement: ข้อมูลที่เก็บจาก SET เองไม่ถูกแทนที่
วันที่มีข้อมูลที่ batch หรือปุ่มดึงข้อมูลเก็บจาก SET อยู่แล้ว SHALL ไม่ถูกเขียนทับด้วยข้อมูลของ InfoQuest ส่วนข้อมูลจาก SET ที่ดึงภายหลัง SHALL เขียนทับวันที่เดียวกันที่มาจาก InfoQuest ได้

#### Scenario: วันที่มีอยู่แล้วจาก SET
- **WHEN** ประวัติมีวันที่ 14 ต.ค. 2026 จาก SET และผู้ใช้รันคำสั่งเติมย้อนหลัง
- **THEN** แถวของวันที่ 14 ต.ค. 2026 ยังเป็นข้อมูลจาก SET

#### Scenario: batch ดึงวันที่เคยเติมไว้
- **WHEN** วันที่ 15 ต.ค. 2026 ถูกเติมจาก InfoQuest แล้ว batch หลังตลาดปิดดึงข้อมูลวันที่ 15 ต.ค. 2026 จาก SET ได้
- **THEN** แถวของวันที่ 15 ต.ค. 2026 เป็นข้อมูลจาก SET

### Requirement: ตรวจก่อนเติมย้อนหลัง
ข่าวแต่ละวัน SHALL มีครบ 4 ประเภท และผลรวมมูลค่าซื้อกับผลรวมมูลค่าขายของ 4 ประเภทต่างกันไม่เกิน 1% และทุกวันที่มีข้อมูลจาก SET อยู่แล้ว ค่าซื้อและขายของทุกประเภทจาก InfoQuest SHALL ต่างจาก SET ไม่เกิน 0.01 ล้านบาท ถ้าข้อใดไม่ผ่าน คำสั่ง SHALL ไม่เขียนข้อมูลใดเลย และแสดงวันที่และเหตุผล

#### Scenario: ข่าวขาดประเภท
- **WHEN** ข่าวของวันหนึ่งมีแค่ 3 ประเภท
- **THEN** คำสั่งไม่เขียนข้อมูลใดเลย และแสดงวันที่นั้นพร้อมประเภทที่ขาด

#### Scenario: ค่าไม่ตรงกับ SET
- **WHEN** ค่าซื้อของต่างชาติวันที่ 14 ต.ค. 2026 จาก InfoQuest ต่างจากที่เก็บจาก SET 5 ล้านบาท
- **THEN** คำสั่งไม่เขียนข้อมูลใดเลย และแสดงวันที่ 14 ต.ค. 2026 ประเภท และค่าทั้งสองแหล่ง

#### Scenario: ไม่มีวันที่เทียบกับ SET ได้
- **WHEN** ประวัติยังไม่มีวันใดจาก SET ที่ตรงกับวันในข่าว
- **THEN** คำสั่งไม่เขียนข้อมูลใดเลย และแสดงว่าต้องมีข้อมูลจาก SET อย่างน้อยหนึ่งวันในช่วงเดียวกันก่อน

#### Scenario: ดึงหน้าข่าวไม่ได้
- **WHEN** InfoQuest ตอบกลับด้วย error ระหว่างดึง
- **THEN** คำสั่งไม่เขียนข้อมูลใดเลย ประวัติเดิมไม่เปลี่ยน และแสดงเหตุผล

### Requirement: ระบุแหล่งที่มาของแต่ละวัน
แต่ละวันในประวัติ SHALL ระบุว่ามาจาก SET หรือ InfoQuest และตารางรายวันบนหน้าเว็บ SHALL ติดป้าย "InfoQuest" ที่วันที่มาจาก InfoQuest

#### Scenario: ตารางมีทั้งสองแหล่ง
- **WHEN** ประวัติมีวันที่ 12 ต.ค. 2026 จาก InfoQuest และ 14 ต.ค. 2026 จาก SET
- **THEN** แถววันที่ 12 ต.ค. มีป้าย "InfoQuest" และแถววันที่ 14 ต.ค. ไม่มี

### Requirement: กราฟมูลค่าสุทธิสะสมรายวัน
หน้าประวัติ SHALL แสดงกราฟเส้นมูลค่าสุทธิ (ซื้อ − ขาย) สะสมรายวันของ 4 ประเภท ใต้กราฟรายเดือน นับสะสมจากวันแรกที่แสดง ไม่เกิน 250 วันทำการล่าสุดที่มีข้อมูล เปิด/ปิดแต่ละเส้นได้ อ่านค่าของแต่ละวันได้ทั้งด้วยเมาส์และคีย์บอร์ด และระบุช่วงวันที่ จำนวนวัน และว่านับเฉพาะวันที่มีข้อมูล

#### Scenario: มีหลายวัน
- **WHEN** ประวัติมีวันที่ 12 ต.ค. 2026 ต่างชาติสุทธิ +266.90 และ 14 ต.ค. 2026 ต่างชาติสุทธิ +5,690.99 ล้านบาท และไม่มีวันอื่น
- **THEN** กราฟมีจุดของต่างชาติ +266.90 ที่ 12 ต.ค. และ +5,957.89 ที่ 14 ต.ค.

#### Scenario: ซ่อนประเภท
- **WHEN** ผู้ใช้กดปุ่มของรายย่อยในประเทศในกราฟรายวัน
- **THEN** เส้นรายย่อยในประเทศของกราฟรายวันถูกซ่อน และกราฟรายเดือนไม่เปลี่ยน

#### Scenario: ข้อมูลน้อยกว่า 2 วัน
- **WHEN** ประวัติมีข้อมูลรายวันแค่ 1 วันหรือไม่มีเลย
- **THEN** หน้าแสดงข้อความว่าข้อมูลรายวันยังไม่พอวาดกราฟแทนกราฟรายวัน และตารางรายวันยังแสดงตามปกติ
