## ADDED Requirements

### Requirement: จำนวนเกณฑ์พื้นฐานที่ไม่ผ่านได้
หมวด quality gate บนหน้า settings SHALL มีช่อง "จำนวนเกณฑ์ที่ไม่ผ่านได้สูงสุด" (default 2) ระบบ SHALL รับเฉพาะจำนวนเต็ม 0 ถึง 4 และ tooltip SHALL อธิบายว่าเพิ่มค่าจะได้ candidates มากขึ้นแต่รวมหุ้นที่พื้นฐานอ่อนกว่า และ 0 คือต้องผ่านทุกเกณฑ์

#### Scenario: ตั้งให้ต้องผ่านทุกเกณฑ์
- **WHEN** ผู้ใช้บันทึกค่าเป็น 0
- **THEN** batch ครั้งถัดไปให้หุ้นผ่าน quality gate เฉพาะเมื่อผ่านทุกเกณฑ์ที่ประเมิน

#### Scenario: ค่าเกินช่วง
- **WHEN** ผู้ใช้กรอกค่า 5
- **THEN** ระบบไม่บันทึกและแสดงข้อความว่าค่าต้องอยู่ระหว่าง 0 ถึง 4
