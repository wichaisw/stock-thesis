## ADDED Requirements

### Requirement: เก็บ candidate ต่อวันที่ราคาปิด
ทุก run ที่สำเร็จ ระบบ SHALL เก็บ evaluation ของหุ้นทุกตัวที่มี `candidate_rank` ใน run นั้น พร้อม `price_date` และ run id ลงตารางประวัติใน transaction เดียวกับการบันทึก run แถวประวัติของ `price_date` เดียวกัน SHALL ถูกแทนด้วยชุดของ run ที่สำเร็จล่าสุดทั้งชุด run ที่ failed SHALL ไม่เขียนประวัติ ประวัติ SHALL ไม่ถูกลบเมื่อ evaluations ของ run เก่าถูกลบ

#### Scenario: run ใหม่ของวันที่ใหม่
- **WHEN** run ของวันที่ราคา 2026-10-16 สำเร็จด้วย candidate 12 ตัว และประวัติมีวันที่ 2026-10-15 อยู่แล้ว
- **THEN** ประวัติมีทั้งสองวันที่ วันที่ 2026-10-16 มี 12 แถว และวันที่ 2026-10-15 ไม่เปลี่ยน

#### Scenario: รันซ้ำวันที่ราคาเดียวกัน
- **WHEN** run แรกของวันที่ราคา 2026-10-15 มี candidate 14 ตัว แล้ว run ถัดมาของวันที่ราคาเดียวกันสำเร็จด้วย candidate 13 ตัว
- **THEN** ประวัติของวันที่ 2026-10-15 มี 13 แถวจาก run หลังเท่านั้น

#### Scenario: run ไม่สำเร็จ
- **WHEN** run ถูกหยุดเพราะเกินเวลา
- **THEN** ประวัติไม่เปลี่ยน

#### Scenario: run ไม่มี candidate
- **WHEN** run ของวันที่ราคาหนึ่งสำเร็จแต่ไม่มี candidate
- **THEN** วันที่นั้นมีในรายการวันที่ของประวัติพร้อมจำนวน 0 ตัว

#### Scenario: เริ่มใช้ครั้งแรก
- **WHEN** engine เปิด DB ที่ยังไม่มีตารางประวัติ และมี run ที่สำเร็จอยู่แล้ว
- **THEN** ประวัติมี candidate ของ run ล่าสุดที่สำเร็จเป็นวันที่แรก

### Requirement: หน้าประวัติ candidate
ระบบ SHALL มีหน้า "ประวัติ candidate" ที่แสดงรายการวันที่ราคาปิดที่มีประวัติ เรียงจากใหม่ไปเก่า พร้อมจำนวน candidate และเมื่อเลือกวันที่ SHALL แสดงตาราง candidate ของวันนั้นด้วยคอลัมน์และลำดับเดียวกับหน้า candidates จากค่าที่เก็บไว้ ชื่อหุ้น SHALL เป็นข้อความธรรมดา ไม่ลิงก์ไปหน้ารายละเอียด หน้า candidates SHALL มีลิงก์ไปหน้านี้

#### Scenario: เปิดหน้าโดยไม่เลือกวันที่
- **WHEN** เปิดหน้าประวัติโดยไม่ระบุวันที่
- **THEN** หน้าแสดงตารางของวันที่ล่าสุด และรายการวันที่ทั้งหมดให้เลือก

#### Scenario: ดูวันก่อนหน้า
- **WHEN** เลือกวันที่ 2026-10-15
- **THEN** ตารางแสดง rank, ราคา, CDC, ETA, MoS และ RRR ตามที่ batch ของวันนั้นประเมินไว้ ไม่ใช่ค่าของวันนี้

#### Scenario: แถวเก่าไม่มี field ที่เพิ่มทีหลัง
- **WHEN** แถวประวัติถูกเก็บก่อนที่ evaluation จะมี field ใหม่
- **THEN** หน้าแสดงแถวนั้นได้ โดยช่องของ field ที่ไม่มีแสดงเป็น "-"

#### Scenario: วันที่ที่ไม่มีในประวัติ
- **WHEN** เปิดหน้าด้วยวันที่ที่ไม่มีในประวัติ
- **THEN** หน้าแสดงว่าไม่มีประวัติของวันที่นั้น และยังแสดงรายการวันที่ให้เลือก
