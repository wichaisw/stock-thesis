# Spec Delta

## ADDED Requirements

### Requirement: ตรวจหุ้นที่ราคาไม่อัปเดต
ระบบ SHALL ติดป้ายราคาไม่อัปเดตให้หุ้นที่ประเมินได้ซึ่งวันที่ของแท่งราคาล่าสุดเก่ากว่าวันที่ราคาของ run (วันที่ราคาล่าสุดในบรรดาหุ้นทุกตัวที่ประเมินได้ใน run นั้น) และ SHALL ให้ผลของ run ที่สำเร็จล่าสุดมีจำนวนหุ้นที่ราคาไม่อัปเดตกับวันที่ราคาที่พบบ่อยที่สุดในกลุ่มนั้น ป้ายนี้ SHALL ไม่ตัดหุ้นออกจาก candidate list และไม่ใช้เรียงลำดับ

#### Scenario: หุ้นส่วนใหญ่ขาดแท่งล่าสุด
- **WHEN** run ประเมินหุ้นได้ 922 ตัว มี 25 ตัวที่แท่งล่าสุดเป็นวันที่ 14 ต.ค. และ 897 ตัวเป็นวันที่ 12 ต.ค.
- **THEN** วันที่ราคาของ run คือ 14 ต.ค. หุ้น 897 ตัวติดป้ายราคาไม่อัปเดต และ run มีจำนวนหุ้นที่ราคาไม่อัปเดต 897 ตัว วันที่ 12 ต.ค.

#### Scenario: ราคาอัปเดตครบ
- **WHEN** หุ้นทุกตัวที่ประเมินได้มีแท่งล่าสุดเป็นวันเดียวกัน
- **THEN** ไม่มีหุ้นตัวไหนติดป้ายราคาไม่อัปเดต และจำนวนหุ้นที่ราคาไม่อัปเดตของ run เป็น 0

#### Scenario: หุ้นที่ราคาไม่อัปเดตแต่ผ่านทุก gate
- **WHEN** หุ้นติดป้ายราคาไม่อัปเดตและผ่านทุกเงื่อนไขของ candidate list
- **THEN** หุ้นยังอยู่ใน candidate list ในลำดับเดียวกับเมื่อไม่มีป้าย
