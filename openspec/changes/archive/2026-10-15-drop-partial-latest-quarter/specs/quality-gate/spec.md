# Spec Delta

## ADDED Requirements

### Requirement: ไตรมาสล่าสุดที่งบยังไม่ครบ
ระบบ SHALL ไม่นับไตรมาสสุดท้ายเป็นไตรมาสที่รายงานแล้ว เมื่อไตรมาสนั้นมี EPS มากกว่า 0 แต่ไม่มีกำไรสุทธิหรือส่วนผู้ถือหุ้น และไตรมาสก่อนหน้ามีทั้งสองค่า quality gate และ fair value panel SHALL ใช้ไตรมาสก่อนหน้าเป็นไตรมาสล่าสุด ระบบ SHALL ไม่นับแบบนี้เฉพาะไตรมาสสุดท้ายไตรมาสเดียว และเหตุผลของเกณฑ์จำนวนไตรมาสขั้นต่ำ SHALL บอกไตรมาสที่ไม่นับ

#### Scenario: ไตรมาสล่าสุดมีแค่ EPS
- **WHEN** ไตรมาส 2026Q3 ของหุ้นมี EPS แต่ไม่มีกำไรสุทธิและส่วนผู้ถือหุ้น และ 2025Q3–2026Q2 มีครบและมีกำไรทุกไตรมาส
- **THEN** ROE TTM และเกณฑ์ไม่ขาดทุนคิดจาก 2025Q3–2026Q2 หุ้นไม่ตกเกณฑ์ ROE ด้วยเหตุผลว่าข้อมูลไม่ครบ และเหตุผลของเกณฑ์จำนวนไตรมาสระบุว่าไม่นับ 2026Q3

#### Scenario: fair value ใช้ไตรมาสเดียวกัน
- **WHEN** ไตรมาสสุดท้ายถูกไม่นับตาม requirement นี้
- **THEN** EPS TTM, กำไร TTM, band และ Justified PBV ใน fair value panel คิดถึงไตรมาสก่อนหน้า ไม่ใช้ EPS ของไตรมาสที่ไม่นับ

#### Scenario: ไตรมาสล่าสุดมีแค่ EPS ที่ติดลบ
- **WHEN** ไตรมาสสุดท้ายมี EPS −0.15 แต่ไม่มีกำไรสุทธิและส่วนผู้ถือหุ้น และไตรมาสก่อนหน้ามีครบ
- **THEN** ระบบนับไตรมาสนั้นเหมือนเดิม และหุ้นไม่ผ่านเกณฑ์ ROE ด้วยเหตุผลว่าข้อมูลไม่ครบ เพื่อไม่ให้หุ้นที่อาจขาดทุนผ่านด้วยงบที่เก่ากว่า

#### Scenario: ไตรมาสก่อนหน้าก็ไม่ครบ
- **WHEN** หุ้นไม่มีกำไรสุทธิในไตรมาสสุดท้ายและไตรมาสก่อนหน้า (เช่นกองทุนที่ thaifin ไม่มีกำไรสุทธิเลย)
- **THEN** ระบบนับทุกไตรมาสที่มี EPS เหมือนเดิม และหุ้นไม่ผ่านเกณฑ์ ROE ด้วยเหตุผลว่าข้อมูลไม่ครบ

#### Scenario: ไตรมาสที่ขาดอยู่ตรงกลาง
- **WHEN** ไตรมาสสุดท้ายมีครบ แต่ไตรมาสหนึ่งใน 4 ไตรมาสล่าสุดไม่มีส่วนผู้ถือหุ้น
- **THEN** ระบบไม่ตัดไตรมาสไหนออก และหุ้นไม่ผ่านเกณฑ์ ROE ด้วยเหตุผลว่าข้อมูลไม่ครบ
