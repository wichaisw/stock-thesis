# Spec Delta

## ADDED Requirements

### Requirement: คัดลอกข้อมูลหุ้นให้ LLM
ระบบ SHALL มีปุ่มคัดลอกบนหน้ารายละเอียดหุ้น เมื่อกดแล้ว SHALL คัดลอกข้อมูลของหุ้นตัวนั้นเป็น Markdown ลง clipboard และ SHALL แสดงให้ผู้ใช้เห็นว่าคัดลอกสำเร็จหรือไม่สำเร็จ ข้อความที่คัดลอก SHALL สร้างจากข้อมูลชุดเดียวกับที่หน้าแสดง ตัวเลขจึงตรงกับหน้า

#### Scenario: คัดลอกสำเร็จ
- **WHEN** ผู้ใช้กดปุ่มคัดลอกบนหน้ารายละเอียดของ KLINIQ
- **THEN** clipboard มีข้อความ Markdown ของ KLINIQ และปุ่มแสดงว่าคัดลอกแล้ว

#### Scenario: คัดลอกไม่สำเร็จ
- **WHEN** เบราว์เซอร์ไม่อนุญาตให้เขียน clipboard
- **THEN** ระบบแสดงว่าคัดลอกไม่สำเร็จ และไม่แสดงว่าคัดลอกแล้ว

### Requirement: Prompt นำสำหรับความเห็นที่สอง
ข้อความที่คัดลอก SHALL ขึ้นต้นด้วย prompt ภาษาอังกฤษที่บอกว่าเป็นการขอความเห็นที่สองของหุ้นใน SET สำหรับนักลงทุนแนว value ที่ถือหุ้นราว 1 ไตรมาส ข้อมูลมาจากแหล่งไม่เป็นทางการ (yfinance, thaifin) ให้ตรวจความสอดคล้องของตัวเลขและแย้งข้อสรุปได้ และ SHALL ขอให้ตอบเป็นภาษาไทย

#### Scenario: วางในแชทของ LLM
- **WHEN** ผู้ใช้วางข้อความที่คัดลอกในแชทของ LLM โดยไม่เขียน prompt เพิ่ม
- **THEN** ข้อความมีคำสั่งให้ตรวจข้อมูล แย้งข้อสรุปได้ และตอบเป็นภาษาไทย อยู่ก่อนข้อมูลของหุ้น

### Requirement: เนื้อหาครบทุกส่วนของหน้า
ข้อความที่คัดลอก SHALL มีทุกส่วนที่หน้ารายละเอียดแสดง ได้แก่ ชื่อหุ้น ชื่อบริษัท sector market ราคาปิดและวันที่ราคา, สถานะใน candidate list และเหตุผลที่ไม่ผ่าน, ผลของทุก gate พร้อมเกณฑ์และค่าจริง, fair value panel (summary, EPS TTM, ป้ายเตือน และทุกเกณฑ์ที่เปิดใช้), CDC, risk/reward, catalyst hints และ event calendar แต่ละส่วน SHALL มีหัวข้อของตัวเอง ป้ายกำกับ SHALL เป็นภาษาอังกฤษ และข้อความที่ได้จาก engine (เช่น เหตุผล) SHALL คงตามเดิม

#### Scenario: หุ้นที่ไม่ติด candidate list
- **WHEN** ผู้ใช้คัดลอกหุ้นที่ไม่ผ่าน gate ROE
- **THEN** ข้อความระบุว่าไม่อยู่ใน candidate list พร้อมเหตุผลทุกข้อ และแถว ROE ระบุว่าไม่ผ่าน พร้อมเกณฑ์และค่าจริง

#### Scenario: เกณฑ์ที่คำนวณไม่ได้
- **WHEN** fair value ของ dividend yield band เป็น N/A ด้วยเหตุผลว่าไม่ได้จ่ายปันผลเงินสดใน 12 เดือนล่าสุด
- **THEN** แถวของเกณฑ์นี้มีอยู่ในข้อความ แสดง N/A และเหตุผลนั้น ไม่ถูกตัดทิ้ง

#### Scenario: หุ้นที่มีป้ายเตือน
- **WHEN** fair value panel มีป้ายโครงสร้างทุนเปลี่ยนหรือข้อมูลย้อนหลังไม่ครบ
- **THEN** ข้อความมีป้ายเตือนนั้นพร้อมเหตุผล

### Requirement: ตัวเลขที่ LLM อ่านไม่ผิด
ข้อความที่คัดลอก SHALL แสดงตัวเลขพร้อมหน่วย (บาท, %, วันทำการ, เดือน) วันที่ SHALL อยู่ในรูป YYYY-MM-DD และค่าที่ไม่มี SHALL แสดงเป็น N/A ตารางของ gates และ fair value SHALL เป็นตาราง Markdown

#### Scenario: ราคาและ MoS
- **WHEN** ราคาปิดคือ 32.75 บาท วันที่ 14 ต.ค. 2026 และ MoS ของ PE band คือ +12.3%
- **THEN** ข้อความแสดงราคา 32.75 THB, วันที่ 2026-10-14 และ MoS +12.3%

### Requirement: คำอธิบายวิธีคิด
ข้อความที่คัดลอก SHALL มีคำอธิบายภาษาอังกฤษหนึ่งบรรทัดของแต่ละเกณฑ์ fair value ที่อยู่ในข้อความ และของสูตร MoS เพื่อให้ LLM ตัดสินได้ว่าเกณฑ์ไหนเหมาะกับหุ้นตัวนั้น

#### Scenario: อธิบาย dividend yield band
- **WHEN** ข้อความมีเกณฑ์ dividend yield band
- **THEN** ข้อความอธิบายว่าเกณฑ์นี้คือปันผลเงินสด 12 เดือนล่าสุด ÷ median yield 12 เดือนใน 5 ปี ไม่นับปันผลเป็นหุ้นและไตรมาสที่ yield ต่ำกว่าเกณฑ์ขั้นต่ำ

### Requirement: หุ้นที่ไม่มีผลประเมิน
ระบบ SHALL ให้คัดลอกได้แม้หุ้นยังไม่มีผลประเมินหรือ fail ใน batch ล่าสุด โดยข้อความ SHALL ระบุสถานะนั้นพร้อมเหตุผล และมีเฉพาะส่วนที่หน้าแสดงได้

#### Scenario: หุ้นที่ดึงข้อมูลไม่ได้
- **WHEN** ผู้ใช้คัดลอกหุ้นที่ fail ใน batch ล่าสุดด้วยเหตุผล "No data found"
- **THEN** ข้อความระบุว่าดึงข้อมูลไม่ได้ใน batch ล่าสุดพร้อมเหตุผลนั้น และยังมี catalyst hints และ event calendar
