# Spec Delta

## MODIFIED Requirements

### Requirement: เนื้อหาครบทุกส่วนของหน้า
ข้อความที่คัดลอก SHALL มีทุกส่วนที่หน้ารายละเอียดแสดง ได้แก่ ชื่อหุ้น ชื่อบริษัท sector market ราคาปิดและวันที่ราคา (พร้อมป้ายราคาไม่อัปเดตเมื่อหุ้นติดป้ายนี้), สถานะใน candidate list และเหตุผลที่ไม่ผ่าน, ผลของทุก gate พร้อมเกณฑ์และค่าจริง, fair value panel (summary, EPS TTM, ป้ายเตือน และทุกเกณฑ์ที่เปิดใช้), CDC, risk/reward, catalyst hints และ event calendar แต่ละส่วน SHALL มีหัวข้อของตัวเอง ป้ายกำกับ SHALL เป็นภาษาอังกฤษ และข้อความที่ได้จาก engine (เช่น เหตุผล) SHALL คงตามเดิม

#### Scenario: หุ้นที่ไม่ติด candidate list
- **WHEN** ผู้ใช้คัดลอกหุ้นที่ไม่ผ่าน gate ROE
- **THEN** ข้อความระบุว่าไม่อยู่ใน candidate list พร้อมเหตุผลทุกข้อ และแถว ROE ระบุว่าไม่ผ่าน พร้อมเกณฑ์และค่าจริง

#### Scenario: เกณฑ์ที่คำนวณไม่ได้
- **WHEN** fair value ของ dividend yield band เป็น N/A ด้วยเหตุผลว่าไม่ได้จ่ายปันผลเงินสดใน 12 เดือนล่าสุด
- **THEN** แถวของเกณฑ์นี้มีอยู่ในข้อความ แสดง N/A และเหตุผลนั้น ไม่ถูกตัดทิ้ง

#### Scenario: หุ้นที่มีป้ายเตือน
- **WHEN** fair value panel มีป้ายโครงสร้างทุนเปลี่ยนหรือข้อมูลย้อนหลังไม่ครบ
- **THEN** ข้อความมีป้ายเตือนนั้นพร้อมเหตุผล

#### Scenario: หุ้นที่ราคาไม่อัปเดต
- **WHEN** ผู้ใช้คัดลอกหุ้นที่ติดป้ายราคาไม่อัปเดต
- **THEN** บรรทัดราคาปิดระบุว่าราคานี้เก่ากว่าหุ้นตัวอื่นใน run เดียวกัน
